ตั้งแต่การสร้างลิงก์รับเงิน ไปจนถึงหน้าจ่ายเงิน การคืนเงิน และการกระทบยอด — จัดการได้จากที่เดียว

Payment Links แบบไม่ต้องเขียนโค้ด

สร้างลิงก์รับเงินระบุยอด เลือกช่องทางที่รับ และตั้งเป็นใช้ครั้งเดียวหรือใช้ซ้ำได้ แล้วแชร์ URL ให้ลูกค้าจ่ายได้ทันที

ไม่ต้องมีทีมพัฒนา

Hosted Checkout สำเร็จรูป

หน้าชำระเงินที่โฮสต์ให้พร้อมใช้ ปรับแบรนด์ร้านได้ ลูกค้าเลือกช่องทางเองและระบบติดตามสถานะจนจ่ายสำเร็จ

หลายช่องทางในหน้าเดียว

บัตร & 3DS 2.x

รับ Visa / Mastercard / JCB พร้อม 3-D Secure 2.x และรองรับ authorize / capture / refund / void รวมถึงการจัดการข้อพิพาท (dispute/chargeback)

PromptPay / Thai QR

สร้าง QR รับเงินตามมาตรฐาน EMVCo/Thai QR แบบไดนามิก ตรวจสอบสถานะการชำระเรียลไทม์ พร้อม webhook ยืนยันการโอน

E-wallet & mobile banking

รองรับ TrueMoney, ShopeePay, Alipay, WeChat Pay, mobile banking และการผ่อนชำระผ่านบัตร ครอบคลุมช่องทางที่คนไทยใช้จริง

Dashboard & การคืนเงิน

ติดตามยอดรับชำระ จำนวนธุรกรรม อัตราสำเร็จและอัตราคืนเงิน ดูรายละเอียดแต่ละรายการ และคืนเงินได้ทั้งเต็มจำนวนหรือบางส่วน

Webhooks & idempotency

รับเหตุการณ์การชำระเงินผ่าน webhook ที่ลงลายเซ็นด้วย signing secret (หมุนคีย์ได้) และส่ง Idempotency-Key เพื่อกันการเรียกเก็บซ้ำ

Settlement & การกระทบยอด

ดูรายการจ่ายเงินเข้าบัญชี พร้อมรายละเอียดค่าธรรมเนียมและยอดสุทธิ ทุกธุรกรรมบันทึกในบัญชีแยกประเภทแบบ append-only กระทบยอดได้โปร่งใส

Tokenization & PCI

ไม่จัดเก็บ PAN เต็มในระบบร้านค้า ข้อมูลบัตรถูกแทนที่ด้วย token ใน tokenization vault ออกแบบตามแนวทาง PCI-DSS และหลักเกณฑ์กำกับดูแลของไทย

ดูของจริง

สินค้าที่ลูกค้าและร้านค้าได้ใช้จริง

หน้า hosted checkout ที่ลูกค้าเห็นตอนจ่ายเงิน และ dashboard ที่ร้านค้าใช้ติดตามธุรกรรมและคืนเงิน

API ที่เข้าใจง่าย เริ่มรับเงินได้ในไม่กี่บรรทัด

REST API สะอาด ตอบกลับด้วย envelope มาตรฐาน รองรับ idempotency key และคิดเงินเป็นหน่วยสตางค์ (satang) แบบ integer เพื่อความแม่นยำ

REST + JSON envelope

ทุก endpoint ตอบกลับด้วย { success, code, data, message } จัดการ error ได้อย่างสม่ำเสมอ

Idempotency ในตัว

ส่ง Idempotency-Key เพื่อป้องกันการเรียกเก็บซ้ำเมื่อเครือข่ายมีปัญหา

ปลอดภัยตั้งแต่ต้น

ยืนยันตัวตนด้วย API key ไม่มีการบันทึก PAN เต็ม ใช้ tokenization vault ทุกครั้ง

create-payment.sh 
# สร้างรายการชำระเงิน ฿1,290.00 (129000 สตางค์)
curl -X POST https://api.paycore.co.th/v1/payments \
  -H "Authorization: Bearer sk_live_••••" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 129000,
    "currency": "THB",
    "method": "card",
    "capture": true,
    "description": "Order #1042"
  }'

# => { "success": true, "data": { "id": "pay_...",
#      "status": "captured", "amount": 129000 } }
