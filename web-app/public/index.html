แพลตฟอร์มรับชำระเงินครบวงจร

ตั้งแต่การรับเงินหน้าร้านออนไลน์ ไปจนถึงการกระทบยอดและการจ่ายเงินเข้าบัญชี — จัดการได้จากที่เดียว

บัตร & 3DS 2.x

รับ Visa / Mastercard / JCB พร้อม 3-D Secure 2.x, capture / refund / void และ dispute แบบครบวงจร ลดการปฏิเสธรายการ (declines) และภาระ chargeback

PromptPay / Thai QR

สร้าง QR รับเงินตามมาตรฐาน EMVCo/Thai QR แบบไดนามิก ตรวจสอบสถานะการชำระเรียลไทม์ และรองรับ webhook ยืนยันการโอน

Settlement & การกระทบยอด

ดูรายการจ่ายเงิน (payouts) เข้าบัญชี พร้อมรายละเอียดค่าธรรมเนียมและยอดสุทธิ กระทบยอดได้ครบทุกธุรกรรมแบบโปร่งใส

Webhooks แบบลงลายเซ็น

รับเหตุการณ์การชำระเงินแบบเรียลไทม์ผ่าน webhook ที่มี signing secret หมุนคีย์ได้ ตรวจสอบความถูกต้องของ payload ได้ทุกครั้ง

Dashboard สำหรับร้านค้า

ติดตาม KPI ยอดขาย อัตราสำเร็จ (success rate), refund ratio และ chargeback จัดการข้อพิพาท คีย์ API และ webhook ได้จากหน้าเดียว

PCI-DSS L1 / สอดคล้อง ธปท.

ไม่จัดเก็บ PAN เต็มในระบบร้านค้า ข้อมูลบัตรถูกแทนที่ด้วย token ในโทเคนไนเซชันวอลต์ ออกแบบให้สอดคล้องกับหลักเกณฑ์กำกับดูแลของไทย

API ที่เข้าใจง่าย เริ่มรับเงินได้ในไม่กี่บรรทัด

REST API สะอาด ตอบกลับด้วย envelope มาตรฐาน รองรับ idempotency key และ money เป็นหน่วยสตางค์ (satang) เพื่อความแม่นยำ

REST + JSON envelope

ทุก endpoint ตอบกลับด้วย { success, code, data, message } จัดการ error ได้อย่างสม่ำเสมอ

Idempotency ในตัว

ส่ง Idempotency-Key เพื่อป้องกันการเรียกเก็บซ้ำเมื่อเครือข่ายมีปัญหา

ปลอดภัยตั้งแต่ต้น

ยืนยันตัวตนด้วย API key ไม่มีการบันทึก PAN เต็ม ใช้ tokenization vault ทุกครั้ง

create-payment.sh 
# สร้างรายการชำระเงิน ฿1,290.00 (129000 สตางค์)
curl -X POST https://api.paycore.co.th/v1/payments \
  -H "Authorization: Bearer sk_live_••••" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 129000,
    "currency": "THB",
    "method": "card",
    "capture": true,
    "description": "Order #1042"
  }'

# => { "success": true, "data": { "id": "pay_...",
#      "status": "captured", "amount": 129000 } }
